# 发布个人构建

此 fork 默认从源码运行。发布者可用自己的 Git 仓库与制品服务器分发桌面或命令行构建。

- 使用根目录的 `dist:desktop:*` 命令构建相应平台的桌面包。签名和公证使用发布者自己的证书。
- 命令行版本归档可放在自有发布地址，通过 `T3CODE_RELEASE_BASE_URL` 配置。桌面更新仓库可以用 `T3CODE_DESKTOP_UPDATE_REPOSITORY` 指定。
- 手机原生构建使用自己的签名、应用标识以及需要的域名。上游热更新已关闭。请在实际设备上验证新包打开时的连接地址和配对过程。
- 托管网页和中继的公开参数参见根目录的 `.env.example`。网页部署在自己的域名上。上传构建前请检查公开清单，签名私钥及服务端密钥只保存在发布者的环境。
